# oura-mcp has moved

This repository is archived. The Oura MCP server now lives in the
[`oura-mcp/` folder of rkennel/me](https://github.com/rkennel/me/tree/main/oura-mcp),
with its full history.

- New work, issues and pull requests go to
  [rkennel/me](https://github.com/rkennel/me).
- The Go module is now `github.com/rkennel/me/oura-mcp`.
- Commits have new IDs there, with the same messages, authors and dates.
  `git log --follow` on a file under `oura-mcp/` shows its history.
- This repository's pull requests and issues stay here, read-only, so old
  links keep working.
- To move a local clone, follow
  [Cutting over from rkennel/oura-mcp](https://github.com/rkennel/me/blob/main/docs/cutover-from-oura-mcp.md).
